Run DiskPeek as Administrator

Administrator rights enable fast MFT scanning — a full C: drive (500 GB) in under 30 seconds instead of several minutes.

  1. Close this browser tab.
  2. Close the DiskPeek server window (Ctrl+C or close the terminal).
  3. Double-click launch-admin.bat in the DiskPeek folder.
  4. Accept the UAC elevation prompt.
